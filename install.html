Install Upglow Reels

Add it to your phone or computer so it opens like a real app — no App Store listing.

Open dashboard

iPhone or iPad

  1. Open this page in Safari (not Chrome or Instagram).
  2. Tap the Share button.
  3. Tap Add to Home Screen, then Add.

Android

  1. Open this page in Chrome.
  2. Tap Install app above, or the menu → Install app / Add to Home screen.

Mac or Windows

  1. Chrome or Edge: click Install app, or the install icon in the address bar.
  2. Safari on Mac: File → Add to Dock.
